# 更新履歴

アプリの「新しくなったこと」とリリースの説明は、ここから作られます。版ごとに `## <版>` の見出しを付け、その下に箇条書きで書きます。

## 0.5.0

- 同期の進み具合が見えるようになりました。サイドバーに進み具合のバーと内容が出て、Android では通知（Android 16 ではライブアップデート）にも表示されます
- Android で、同期中にアプリを離れても同期が最後まで続くようになりました
- Android で、アプリを開いていなくても一定の間隔で同期するようになりました（設定 → 同期 → バックグラウンドで同期）。書いてすぐ別のアプリに移ったときも、その変更をバックグラウンドで送ります
- 更新したあと最初に開いたとき、この「新しくなったこと」が表示されるようになりました（設定 → アップデート → 更新履歴 からも読めます）
- スマホで、チェックリストのチェックを押すと画面がカーソルの位置へ飛ぶ問題を直しました
- スマホの日本語入力で、【】などのかっこを確定すると閉じかっこが 2 つ入る（【】】）問題を直しました
- スマホで、文字を選んだときに出ていた書式のメニューをなくしました（Android のメニューと重なっていたため）
- スマホの画面を作り直しました。下のタブバー（ノート・日記・ToDo・検索・設定）、右下の「＋」ボタン、ノートを右へスワイプでピン留め・左へスワイプでゴミ箱、一覧を下に引いて同期、設定は 1 つの画面に。ボタンや入力欄は押しやすい大きさにし、押したときの動きと軽い振動を付けました。下から出るメニューは下へ引いて閉じられます
- スマホの数式の入力を作り直しました。全画面のシートで、上に大きなプレビュー、下に記号のキー（実際の記号で表示）。記号のキーを使う間はキーボードを出さず、ボタンで切り替えられます
- 行番号の位置が本文と少しずれていたのを直しました（数字が本文と同じ行の線に乗ります）
- 一覧の抜粋で、数式が TeX のまま表示されていたのを「［数式］」にしました
- 本文の数式（ブロック）を、分数などが小さくならない大きさで表示するようにしました
- スマホのノート一覧を区切り線のある平らな一覧にし、スクロールバーを細くしました
- 英語表示のときに行番号が少し下にずれる問題と、数式シートの記号グループ名が日本語のままだった問題を直しました

## 0.4.0

- アプリの名前を「日色」にしました
- ノートブックに色を付けられるようになりました
- チェックリストのチェックと文字の高さがそろうようにしました
- スマホで、アプリを切り替えて戻ったときに同期のエラー（Google Drive など）が出る問題を直しました
- スマホで、文字を長押しして選んだときに下からメニューが出る問題、キーボードが出るときにダイアログの位置がずれる問題を直しました
- 数式の入力画面をスマホで使いやすくし、プレビューで式が切れる問題を直しました
- まれに書いている文字が消えることがある問題に対策しました

## 0.3.0

- 別の端末で書き換えられたノートを上書きせず、競合コピーとして残すようにしました。競合コピーは違いを見ながら、どちらを残すか選べます
- 検索が全角・半角、ひらがな・カタカナを区別しなくなりました。`tag:` と `in:` で絞り込めます
- 自動バックアップ、使われていない添付ファイルの整理、作品の EPUB（縦書き・横書き）書き出し、タスクの期限の通知、`[[` でのノートへのリンク、本文の横に別のノートを出す「資料」パネルを加えました
- タスクを追加するノートブックを選べるようにしました
- そのほか多くの不具合を直しました
